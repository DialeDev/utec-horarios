# Horarios UTEC

Construí tu horario semanal de la UTEC en minutos. Subí tu hoja de asesorías, seleccioná tus secciones y exportalo como PDF.

## Stack

React 19 · Vite 7 · Tailwind CSS 4 · React Router 7 · jsPDF · pdfjs · react-icons · sonner

## Quick Start

```bash
git clone https://github.com/DialeDev/utec-horarios.git
cd utec-horarios
pnpm install
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173)
